# AnimeHubWatch

A streaming anime website inspired by the Kitsune concept, adapted into this repo and ready to run locally.

## Local setup

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Features

- Anime landing page
- Search-ready hero section
- Anime detail pages
- Watch page with embedded player
- Responsive dark UI

## Production build

```bash
npm run build
npm run start
```
